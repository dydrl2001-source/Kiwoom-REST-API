# 종목별 AI 보고서 — 저장 결과 열람

## 이번 변경

- 재료·뉴스 탭 맨 위에 종목별 외부 AI 보고서 목록을 추가한다.
- 조회순위 / 거래대금 표에서 6자리 종목코드로 연결한 `AI 보고서` 또는 `AI 상태` 버튼을 표시한다. 원래 규칙 기반 재료 요약은 덮어쓰지 않는다.
- 최근 7일, 최근 시도 기준 최대 50종목을 조회한다. 종목명·코드 검색과 보고서 있음 / 최근 실패 / 대기·진행 중 필터를 제공한다.
- 최근 조사 시도와 마지막 인용 포함 보고서를 별도로 표시한다. 이후 조사가 실패했어도 이전 저장 보고서를 실패 상태와 함께 볼 수 있다.
- 보고서는 문장 속 클릭 가능한 인용을 유지한다. 본문을 HTML이나 JavaScript로 실행하지 않는다.
- 작성 시각, 그 보고서에 사용된 시장 수집 시각, 가격봉 시각을 구별한다. 작성 후 6시간 경과 표시는 보고서의 나이일 뿐 뉴스 유효기간 판정이 아니다. 모든 저장 보고서는 현재 시세와 별도로 확인한다.

## 색과 의미

초록: 저장된 인용 포함 보고서. 사실·인과 검증 완료나 매매 신호를 뜻하지 않는다.
파랑: 조사 대기/진행 상태.
빨강: 최근 실패/완료 여부 미확인.
노랑: 작성 후 6시간 경과.

## 비용·운영 경계

새 `GET /api/report-library`는 기존 DASHBOARD_TOKEN 인증을 요구하며 DB의 읽기 전용 트랜잭션으로 저장 기록만 읽는다. 유료 API를 호출하거나 재시도·작업 등록·한도 수정·기록 삭제를 하지 않는다. 새로운 worker를 만들지 않는다. 기존 수동 1회/자동 꺼짐 설정과 키는 변경하지 않았다.

앞선 인증 실패 재시험이 실제 성공했는지는 아직 확인되지 않았다. 보고서가 없는 경우 빈 상태 또는 실패 기록을 표시하며, 로컬 규칙 요약을 외부 AI 분석 완료라고 표시하지 않는다. 기존 리서치 탭의 별도 조사 버튼은 여전히 유료 요청용이다. 이번 `AI 보고서 열기`와 `저장 결과 새로고침` 버튼은 열람 전용이다.

## Mac mini 적용

```bash
(
  set -e
  cd "$HOME/Kiwoom-REST-API"
  git -c core.fileMode=false pull --ff-only
  cd market_radar/local
  docker compose up -d --no-deps --build radar-api
  sleep 5
  bash check_report_library.sh
)
```

현재 대시보드가 정상 구동되고 DB가 실행 중인 환경을 전제로 한다. radar-api만 재생성하며 web-research-worker를 시작하지 않는다. Git 충돌 시 중단하고 restore/reset, .env 덮어쓰기, DB 삭제를 자동으로 하지 않는다. UI 적용 후 기존 주소에서 새로고침하고 `재료·뉴스` 탭을 연다.

`SAVED_CITED_REPORTS: 0`은 이 조회 범위에 표시할 인용 포함 보고서가 없다는 뜻이며 즉시 시스템 장애를 뜻하지 않는다. 진단 스크립트는 보고서 본문, 키, 계좌정보를 출력하지 않는다.

## 검증

개발 환경에서 22개 모의 단위/인증/읽기 전용/오류 격리 테스트, Python·Bash·JavaScript 문법 검사를 통과했다. Chromium에 가상 DOM과 fetch 응답을 주입해 검색/필터, 종목코드별 연결, 인용, 악성 문자열의 텍스트 표시, 표 갱신 후 버튼 복원, 모바일 배치와 Esc 닫기를 확인했다. 네트워크 탐색은 사용하지 않은 오프라인 브라우저 검사다.

실제 사용자 Mac mini, 실제 Postgres 쿼리 실행, 실제 OpenAI 보고서 생성은 이번 변경에서 검증하지 않았다. 현재 변경은 유료 분석 결과를 만들어 낸 것이 아니라 저장 결과의 열람 기능이다.

```bash
python -m unittest discover -s market_radar/tests -p 'test_report_library.py' -v
node --check market_radar/report_library_ui.js
```
